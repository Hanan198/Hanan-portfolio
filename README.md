# Noor Medical Clinic Website

A complete responsive English medical clinic website built with:
- HTML
- CSS
- JavaScript

## How to run
1. Extract the ZIP file.
2. Open `index.html` in your browser.
3. Edit clinic details in `index.html`.
4. Change colours in the `:root` section at the top of `style.css`.
5. The appointment form is currently a front-end demo and does not send data to a real database.

## Before publishing
- Replace the clinic name, phone number, email, and address.
- Connect the booking form to a backend, Formspree, Firebase, or another service.
- Add privacy policy and terms pages.
- Replace demo images with licensed or real clinic images.
